# Third-party source notices

RealTool-Loc contains compact curated records associated with public tools and services. The list below records documentation endpoints as source context. Inclusion here does not imply that one artifact-level license replaces an upstream provider's terms. Users should consult the linked provider documentation before redistributing or using associated upstream material outside this research artifact.
